# CloudEdge Ops 完善计划

## 项目定位

项目原名 CloudEdge AI，现名 CloudEdge Ops。面向工业设备和机器人设备的云边运维作品，核心价值是可验证的设备运维闭环：遥测采集、设备影子、异常告警、操作员处理、OTA 命令、状态恢复和审计。当前实现使用 Node.js、HTTP、SSE、原生浏览器界面和 JSON 文件；模拟器代表边缘设备。

## 现状评估

开始本轮检查时，已有 24 项测试通过，工作区存在尚未提交的 v0.3 开发成果。基础业务完整，但实现、文档与自动化验收未同步；备份写入的原子性、命令过期权限、运行配置及凭据验证存在缺口。优先稳定当前业务，再扩展技术栈。

## v0.4 实际交付（2026-09-07）

完成受保护模式私有读取、设备详情隔离、SSE 专用短期会话、退出与过期失效、健康信息脱敏、失败认证限流和重复 Token 配置校验。接口测试与浏览器流程验证覆盖这些行为。

原路线图中的多用户登录、凭据热轮换、分页和审计保留没有在本版实现，继续列为后续任务。当前只有一个配置式操作员身份，不能宣称已完成完整账户体系或生产部署能力。

## 可展示证据

每个后续版本附演示流程、运行截图、测试结果、故障恢复记录及实际测量条件。吞吐、稳定性、硬件兼容性和 AI 准确率只报告实际测量值。当前 OTA 是命令流程模拟，没有真实固件下载、签名验证和回滚。
