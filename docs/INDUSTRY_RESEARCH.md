# 行业资料与术语依据

## 调研范围

本次查阅 AWS IoT、Azure IoT Hub 和 ThingsBoard 官方公开文档，提取面向设备运维、IoT 平台研发与交付售后人员的术语和工作流。资料均实际访问并读取，访问日期为 2026-09-07。此处是产品文档调研，不是用户访谈，也不是行业标准认证。

| 来源 | 官方说明要点 | 本项目采用方式 |
| --- | --- | --- |
| [AWS IoT Device Shadow document](https://docs.aws.amazon.com/iot/latest/developerguide/device-shadow-document.html) | reported 为设备上报状态，desired 为期望状态；状态时间戳可用于判断数据年龄 | 明确上报/期望固件版本、版本一致性、最近接收时间 |
| [Azure IoT Hub device twins](https://learn.microsoft.com/en-us/azure/iot-hub/iot-hub-devguide-device-twins) | 设备孪生存储状态、配置、条件；reported properties 适合最近状态，遥测序列适合时序数据 | 区分设备影子与遥测趋势，不将二者混称为实时设备状态 |
| [ThingsBoard alarms](https://thingsboard.io/docs/user-guide/alarms/) | 告警确认和 active/cleared 是两个维度；severity、originator、type、时间和处置记录帮助操作员分诊 | 界面分别呈现处置状态和最近采样工况；关闭告警要求填写处置记录 |
| [AWS IoT Jobs](https://docs.aws.amazon.com/iot/latest/developerguide/iot-jobs.html) | Jobs 用于设备远程操作，可包括固件更新、证书轮换与排障 | 使用“升级任务”“任务执行记录”，明确本项目 OTA 是模拟任务 |

## 角色与工作问题

- 设备运维：哪些设备上报超时？哪些告警待确认？当前采样是否仍超限？已经采取了什么措施？
- 嵌入式/IoT 研发：设备期望与上报状态是否一致？采样和接收时间是否不同？命令在哪一阶段结束？
- 交付售后：设备标识和固件版本是什么？异常发生时有哪些观测证据？交接记录是否完整？

## 本版统一用语

| 界面用语 | 含义与限制 |
| --- | --- |
| 设备台账 | 已注册设备目录；不等于含采购、维修、报废流程的完整 EAM 资产系统 |
| 上报固件版本 / 期望固件版本 | reported / desired；不一致是版本差异，不直接判定升级失败 |
| 最近接收时间 | 服务端收到遥测的时间，在线判定使用此时间 |
| 遥测观测时间 | 设备上报 timestamp，未提供时由服务端生成；没有时钟同步保证 |
| 上报超时 | 超过本地配置的遥测静默阈值，不等同于硬件停机、网络断开或设备损坏 |
| 温度超上限 / 振动速度超上限 | 本地演示规则越限，不等同于预测性维护诊断 |
| 待确认 / 已确认 / 已关闭 | 保留 API 的 open / acknowledged / resolved 工作流；关闭是处置记录，不是工况恢复证明 |
| 最近采样仍超限 / 最近采样未超限 / 工况未知 | 由最近一条有效遥测与该告警阈值比较；离线或缺失指标时为未知，没有增加持久化告警状态机 |
| 处置记录 | 人工关闭时提交的检查结果、措施与后续安排，保存到现有 resolutionReason |
| OTA 升级任务（模拟） | 模拟排队、确认、下载、安装和终态；没有真实固件校验、回滚和硬件验证 |

## 避免误用

1. 本地 65 °C、7.5 mm/s 等阈值是演示规则，未按特定设备规格整定。振动指标没有声明 RMS/峰值、频带、轴向、测点或 ISO 20816 合规性，不能用于设备健康判级。
2. ThingsBoard 的四状态告警模型没有直接照搬；本项目保留既有三状态处置 API，并增加独立的当前观测展示，不宣称已实现完整告警管理标准。
3. 当前没有工单、CMMS/EAM、OEE、MTBF、预测性维护模型或真实数字孪生仿真。不得通过界面命名暗示这些能力。
4. 趋势图按服务端接收时间绘制最近 48 个有效采样点；不是历史数据库、聚合分析或连续采样保证。

## 后续调研与验收

下一步应与实际运维人员确认设备命名、站点分组、告警优先级、值班交接字段及关闭权限；与设备工程师确认指标量纲、采样周期、测点、阈值来源和恢复滞回。没有这些输入前，不将演示阈值推广为通用行业规则。
